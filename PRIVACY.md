# Privacy notes

This public repository contains no operational Priorena workspace.

The included demo fixture is independently fictional. Names, Jira keys, project descriptions, evidence excerpts, owners, milestones, and briefing examples in the demo and tests are synthetic and are not sanitized copies of private records.

When Priorena runs locally, workspace state and uploaded source files stay on the local machine unless the user explicitly invokes an optional AI drafting feature. If a provider is configured, only the content required for that selected drafting request is sent to the fixed provider endpoint.

Priorena does not include analytics, registration, telemetry, advertising, or an automatic publishing integration. It does not receive or store original screenshots.

Users remain responsible for:

- keeping `.env` and `.priorena-data/` private;
- using only information they are authorized to process;
- choosing an organization-approved AI provider;
- removing secrets and unrelated personal information before any external transcription workflow;
- reviewing every extracted finding and communication before use.
